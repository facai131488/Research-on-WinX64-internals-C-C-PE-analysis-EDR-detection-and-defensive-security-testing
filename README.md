WinX64 Security Research

中文介绍

项目简介

本项目专注于 Win x64 平台安全研究，主要围绕 C++、C# 两种编程语言，探讨 Win 底层机制、PE 文件分析、AV/EDR 检测与免杀技术研究。

重点是本人愿意给付出专业知识和建议的大佬们相应的酬谢

研究方向

Windows x64 底层机制：进程、线程、内存管理及 Windows API。

C++ 版本：Windows 原生程序开发、底层机制分析与安全研究。

C# 版本：.NET 运行时机制、Windows API 调用及安全测试。

PE 文件分析：可执行文件结构、加载机制与二进制分析。

AV/EDR 免杀研究：安全软件检测机制、行为分析及授权环境下的检测评估。

安全检测与防御：检测规则、遥测数据分析、误报研究及防御技术。

双语言研究

项目将尽可能针对相同的研究主题提供 C++ 和 C# 两种实现，比较不同语言在 Windows x64 环境中的运行机制、系统 API 调用和程序行为。

技术交流

欢迎 Windows 开发者、逆向工程人员和安全研究人员参与讨论，分享研究成果、分析思路、实验记录及技术文档，共同学习和改进。

本项目主要用于技术学习、授权安全测试及防御研究。

English Introduction

About

This project focuses on Windows x64 security research, covering C++, C#, Windows internals, PE analysis, AV/EDR detection, and security evasion research.
I welcome guidance from experienced professionals and am happy to offer something in return for their time and expertise.
Research Topics

Windows x64 Internals — Processes, threads, memory management, and Windows APIs.

C++ Implementation — Native Windows development, system-level programming, and security research.

C# Implementation — .NET runtime behavior, Windows API integration, and security testing.

PE Analysis — Executable file structures, loading mechanisms, and binary analysis.

AV/EDR Evasion Research — Detection mechanisms, behavioral analysis, and authorized security evaluation.

Detection and Defense — Detection rules, telemetry analysis, false-positive investigation, and defensive techniques.

Dual-Language Implementations

Where practical, research topics will include both C++ and C# implementations to compare runtime behavior, Windows API interactions, and language-specific characteristics.

Collaboration

Windows developers, reverse engineers, and security researchers are welcome to contribute technical discussions, research notes, documentation, and reproducible experiments.

The project is intended for educational purposes, authorized security testing, and defensive research.

Let's learn, research, and share knowledge together!
